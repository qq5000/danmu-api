# 设备兼容提醒

以下项目通过了源码和接口检查，但还依赖特定运行环境：

- `redguo.py` 写有 `192.168.31.222:9999` 和 `192.168.31.222:8800` 两个局域网服务地址；换设备后需要替换成实际服务地址。
- `stripchat直播 高画质版.py` 会调用宿主常用的 `127.0.0.1:9978/9979` 服务，并依赖 `getProxyUrl()`。
- `catemby_spider.py` 使用宿主 `127.0.0.1:9978/proxy`，并支持外部 Alist 配置。
- `草榴视频区.py`、`黄色仓库.py`、`撸王宝典🔞.py` 会在本机启动临时图片代理端口；部分受限电视端 Python 环境可能禁止监听端口。
- `hanime1.py` 的 `cloudscraper` 为可选依赖；缺少时会退回 `requests`。
- `MissAV(自己填ck).js` 是 Widget JavaScript 脚本，并且需要单独填写 Cookie，因此保存在 `unsupported/`。

清单中的 `valid: true` 表示语法、Spider 接口和清单结构合格，不代表目标网站当前一定在线。网站域名、接口和反爬规则会随时间变化。
